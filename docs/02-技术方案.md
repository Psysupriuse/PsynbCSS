# 技术方案 — Psy剪贴板

版本:1.0 | 更新日期:2026-09-20

## 1. 技术选型

| 项 | 选型 | 理由 |
|---|---|---|
| 桌面框架 | Electron(最新稳定版) | 开发调试打包全在本机完成,生态成熟 |
| 前端 | 原生 HTML/CSS/JavaScript | 无框架、无构建步骤,简单可维护 |
| 打包 | electron-builder → NSIS 安装包 | 标准方案,双击安装 |
| 依赖 | 运行时零依赖 | 自动粘贴用系统自带 PowerShell |

开发期依赖仅:electron、electron-builder、cross-env。

## 3. 进程架构

- **主进程**(main.js):托盘、全局快捷键、剪贴板轮询、数据存储、清理任务、自动粘贴、窗口管理
- **渲染进程**(renderer/):列表/设置界面,只通过 preload 暴露的 `window.psy` API 与主进程通信
- **安全**:contextIsolation 开启、nodeIntegration 关闭、CSP 限制 `default-src 'self'; img-src 'self' data:`

## 4. 数据设计

存储位置:`app.getPath('userData')`(即 `%APPDATA%\Psy剪贴板\`,开发与安装版一致;测试/截图模式用项目内 `.devdata/` 隔离,不影响真实数据)

| 文件 | 内容 |
|---|---|
| history.json | 条目数组 `{ id, type: 'text'|'image', text?, pinned, pinnedAt?, createdAt }`,按 createdAt 倒序 |
| images/<id>.png | 图片内容,文件名 = 条目 id;删除/清理条目时同步删除 |
| settings.json | `{ retentionDays: 3, hotkey: 'Control+Alt+V', filterPasswords: true, pasteOnClick: true, autoStart: true }` |

## 5. 关键机制

### 5.1 剪贴板轮询
- 每 700ms 轮询一次(Windows 无剪贴板变更事件,轮询是行业通用做法,如 Ditto)
- **重要:Electron 44 起剪贴板 API 为异步**,`clipboard.read(): Promise<ClipboardItem[]>` / `readText(): Promise<string>` / `write(data: ClipboardItem[]): Promise<void>`;旧的同步 `readImage/writeImage` 已移除(2026-09-20 实测确认)
- 读取:遍历 ClipboardItem 的 MIME 类型,有 `image/*` 优先取图片(getType → Blob → nativeImage),否则读纯文本
- 去重:内容哈希与最近一次记录对比,相同则跳过 → 连续复制相同内容只记一次;图片按解码后的像素数据(toBitmap)哈希——系统会重编码 PNG,字节级哈希不稳定
- 轮询有防叠加保护(异步读取未完成时跳过本轮)
- 启动时记录当前剪贴板为基线,只记录"新复制"的内容
- 回贴写入剪贴板时同步更新哈希,避免把自己的写入记录成新条目(阶段 4)

### 5.2 智能过滤
正则匹配疑似密码/验证码文本(保守规则,见 main.js `PASSWORD_PATTERNS`),命中即跳过;设置页可开关。

### 5.3 自动粘贴
卡片点击 → 主进程写入剪贴板 → 隐藏窗口 → 焦点自动回到前一应用 → PowerShell `WScript.Shell SendKeys('^v')` 模拟 Ctrl+V。失败兜底:内容已在剪贴板,手动 Ctrl+V 即可。

### 5.4 到期清理
启动时 + 每小时:删除 `createdAt` 早于「现在 − 保留天数」且未置顶的条目,同步删除图片文件。

### 5.5 容量上限
普通条目最多 500 条;超出时删除最旧的非置顶条目;置顶条目豁免,不计入上限。

### 5.6 单实例
`requestSingleInstanceLock`,二次启动时唤起已有面板。

## 6. 已知限制与注意事项

- 富文本仅保留纯文本;文件复制不记录(见需求 §6)
- 图片缩略图显示时由主进程压缩(原图保留用于回贴)
- 打包产物未签名,首次运行可能被 SmartScreen 提示(点"仍要运行"即可)
- 开机自启仅在安装版生效(开发模式下跳过,避免注册无效启动项)
