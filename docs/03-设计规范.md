# UI 设计规范 — Psy剪贴板

版本:1.0 | 更新日期:2026-09-20

## 1. 设计原则

简洁、直观、无多余装饰;一次点击完成核心操作;中文界面;改动任何 UI 前先读本文件。

## 2. 配色(淡蓝主题)

| 用途 | 色值 |
|---|---|
| 主色(淡蓝) | `#5BA8E0` |
| 主色加深(悬停/按下) | `#3D8CC7` |
| 主色浅底(置顶卡) | `#E3F1FB` |
| 页面背景 | `#F2F8FC` |
| 卡片背景 | `#FFFFFF` |
| 边框 | `#DCEBF5` |
| 正文文字 | `#333A45` |
| 次要文字(时间等) | `#8A96A3` |
| 危险色(删除) | `#E0655B` |

标题栏:淡蓝渐变底(`#6DB5E8 → #5BA8E0`),白色文字。

## 3. 布局

- 面板窗口:380×560(最小 320×420),无边框,自绘标题栏
- 标题栏:左侧应用名(logo + "Psy剪贴板"),右侧 ⚙ 设置、✕ 收起;整条为可拖动区域
- 搜索框:圆角胶囊样式,标题栏下方
- 卡片列表:上下滚动,占满剩余空间

## 4. 卡片规范

- 白底、圆角 10px、浅蓝边框;悬停描边加深 + 轻阴影 `0 2px 8px rgba(91,168,224,.18)`
- **文字卡**:最多 3 行预览(`pre-wrap`,超出截断,可选中复制);相对时间 + 悬停显示完整时间
- **图片卡**:缩略图最大高 240px(显示时主进程压缩,原图保留用于回贴);加载失败显示占位
- **置顶卡**:淡蓝底 `#E3F1FB` + "📌 置顶"小徽标(主色底白字)
- 悬停显示操作按钮(右上角):置顶/取消置顶、删除(危险色)
- **点击卡片主体 = 回贴**

## 5. 交互规范

- 点击托盘图标或按全局快捷键:面板在鼠标位置弹出并聚焦
- 失焦约 500ms 自动隐藏;Esc 或 ✕ 收起(不退出)
- 搜索实时过滤,不区分大小写;搜索非空时仅显示匹配的文字条目
- 删除需确认(单条为按钮式直接删,清空为二次确认);置顶即时生效
- 置顶组在上(按置顶时间倒序),普通组按复制时间倒序
- 相对时间:刚刚 / N 分钟前 / N 小时前 / N 天前 / 超过 30 天显示完整日期时间

## 6. 字体

`Segoe UI, "Microsoft YaHei", system-ui`;正文 13px,次要信息 11px,行高 1.5。
