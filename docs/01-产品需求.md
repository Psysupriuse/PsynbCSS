# 产品需求文档(PRD)— Psy剪贴板

版本:1.0 | 更新日期:2026-09-20 | 状态:已确认

## 1. 产品定位

Windows 平台的剪贴板历史工具:自动记录用户复制的文字与图片,支持按时间查看、搜索、置顶、一键回贴,按设定期限自动清理。

## 2. 目标用户

个人用户(产品使用者即需求提出者)。

## 3. 功能需求

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 自动记录 | 实时监测剪贴板,记录文字和图片内容 | P0 |
| F2 | 去重 | 连续复制相同内容只记录一次 | P0 |
| F3 | 历史查看 | 打开面板,卡片按时间倒序排列 | P0 |
| F4 | 再次粘贴 | 点击卡片自动粘贴回正在使用的软件 | P0 |
| F5 | 置顶 | 置顶卡片排在列表最前,永久保留不被清理 | P0 |
| F6 | 删除 | 单条删除 + 清空全部 | P0 |
| F7 | 搜索 | 按关键词实时过滤文字内容 | P0 |
| F8 | 保存期限 | 1/3/5 天预设 + 自定义天数,到期自动清理 | P0 |
| F9 | 智能过滤 | 自动跳过疑似密码/验证码内容(可开关) | P1 |
| F10 | 托盘常驻 | 任务栏托盘图标,左键弹出面板,右键菜单 | P0 |
| F11 | 全局快捷键 | 默认 Ctrl+Alt+V,可自定义 | P0 |
| F12 | 开机自启 | 默认开启,可关闭 | P1 |

## 4. 非功能需求

- 界面:简洁直观,淡蓝色主色调(详见 docs/03-设计规范.md)
- 性能:剪贴板监测延迟 < 1 秒;面板弹出即时
- 隐私:所有数据仅存本机,无任何网络请求
- 容量:最多保存 500 条(置顶条目不受清理影响)
