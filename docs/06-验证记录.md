## 五、开发过程中发现并修复的问题（Bug 记录）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 登录页无背景图、卡片未居中（服务端返回内容正常） | head.ejs 用转义输出 `<%= %>` 拼接 class 属性，双引号被转义为 `&#34;`，浏览器解析后 class 值带字面引号，`.auth-body` 选择器匹配失败 | 属性拼接改用不转义输出 `<%- %>`；headless 截图+像素采样复验通过 |

## 六、测试过程中的非应用问题说明

- curl（Git Bash）发送中文表单数据按 GBK 编码导致服务端存乱码——浏览器表单始终 UTF-8，应用无此问题；中文测试改用 Node fetch 脚本（UTF-8）执行，全部通过；
- 会话 MemoryStore：服务重启后需重新登录，V1.0 可接受。
