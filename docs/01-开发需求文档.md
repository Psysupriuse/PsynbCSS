# 校园活动管理系统 V1.0 开发需求文档

> 实验来源：基于工程意图的软件迭代开发实验
> 产品形态：Web 网站
> 主色调：蓝色系（校园清爽风格）

## 1. 项目概述与核心问题

### 1.1 原始业务

1. 用户注册登录
2. 学生：查看、参与校园活动
3. 组织教师：发布、管理校园活动

V1.0 不求功能多，优先保证业务流程跑通、结构合理、可运行；Git 完整记录开发全过程，提交代码 + 实验报告。

### 1.2 系统要解决的现实问题

| 编号 | 问题 |
|---|---|
| P1 | 线下海报、微信群发布活动，信息分散，学生获取活动消息不方便 |
| P2 | 教师发布活动、统计报名学生依靠 Excel 手工统计，效率低、容易出错 |
| P3 | 活动报名没有统一线上入口，报名状态无法查看 |
| P4 | 用户身份不区分：普通学生不能发布活动，教师拥有活动管理权限 |

## 2. 工程意图

1. **为什么建设 V1.0**：实现校园活动基础数字化，解决活动发布、浏览、报名基础业务，完成可运行最小可用 Web 版本；
2. **主要解决问题**：学生线上浏览报名活动；教师线上发布维护活动；区分两种角色权限；
3. **本轮完成内容**：注册登录、角色区分、活动发布、活动浏览、活动报名、个人中心；
4. **约束条件**：Web 网站（不做小程序/APP）；使用 Git 持续提交（禁止最后一次性上传代码）；不存储真实隐私密码（密码加密存储）；AI 生成代码需人工校验；
5. **完成判定标准**：
   - 学生账号：可以注册登录，浏览活动、报名活动、查看我的报名记录；
   - 教师账号：可以登录，新增/编辑/删除活动，查看本活动报名学生名单；
   - 不同角色菜单权限隔离；
   - 网站可以完整启动，核心业务流程跑通。

## 3. 角色定义

| 角色 | 标识 | 权限范围 |
|---|---|---|
| 学生用户 | student | 浏览活动、查看详情、报名活动、查看我的报名记录、个人中心 |
| 教师用户 | teacher | 发布/编辑/删除自己创建的活动、查看活动报名名单、后台统计、个人中心 |

## 4. 页面清单

### 4.1 公共页面（未登录）

1. **注册页面**：用户名、密码、确认密码、选择角色【学生/教师】、注册按钮、跳转登录链接。
2. **登录页面**：账号密码输入框、登录按钮、跳转注册链接；登录成功按角色跳转对应首页。

### 4.2 学生端页面（登录后）

1. **学生首页（活动列表页）**：蓝色顶部导航栏；活动卡片列表（标题、时间、地点、主办方、简介）；可按活动筛选；卡片按钮：查看详情。
2. **活动详情页**：完整活动信息（标题、时间、地点、教师主办方、活动介绍、最大报名人数）；【立即报名】按钮；已报名显示"已报名，不可重复报名"。
3. **我的报名页面**：我报名的全部活动列表（活动名称、活动时间、报名状态）；查看详情入口。
4. **个人中心页面**：账号信息展示、修改密码、退出登录。

### 4.3 教师管理端页面（登录后）

1. **教师后台首页**：蓝色侧边管理菜单；简单统计：总活动数、待开始/已结束活动数量。
2. **活动管理列表页**：教师自己发布的全部活动（标题、时间、状态）；操作：编辑、删除、查看报名人员。
3. **新增/编辑活动页面**：表单（活动标题、活动时间、活动地点、活动简介、最大报名人数）；保存提交。
4. **活动报名名单页**：该活动所有报名学生列表（展示学生用户名）；仅查看，V1.0 不做导出。
5. **教师个人中心**：修改密码、退出登录。

## 5. 功能需求表

### 5.1 用户账号模块

| 编号 | 功能 | 角色 | 说明 |
|---|---|---|---|
| FR-01 | 用户注册 | 学生、教师 | 填写用户名密码、选择身份角色、创建账号；用户名不能重复 |
| FR-02 | 用户登录 | 学生、教师 | 账号密码校验，登录网站，按角色跳转对应首页 |
| FR-03 | 修改密码 | 学生、教师 | 登录后修改自己账户密码 |
| FR-04 | 退出登录 | 学生、教师 | 清除登录状态，跳转回登录页面 |

### 5.2 学生活动模块

| 编号 | 功能 | 角色 | 说明 |
|---|---|---|---|
| FR-05 | 浏览全部活动 | 学生 | 查看教师发布的公开活动列表，卡片展示基础信息 |
| FR-06 | 查看活动详情 | 学生 | 点开活动查看完整信息 |
| FR-07 | 活动报名 | 学生 | 对未开始活动提交报名；不能重复报名；人数满员无法报名 |
| FR-08 | 查看我的报名记录 | 学生 | 查看本人所有报名活动与状态 |

### 5.3 教师活动管理模块

| 编号 | 功能 | 角色 | 说明 |
|---|---|---|---|
| FR-09 | 创建新活动 | 教师 | 填写表单发布校园活动，对外学生可见 |
| FR-10 | 编辑已有活动 | 教师 | 修改自己发布的活动信息；活动已报名后依然可以编辑基础信息 |
| FR-11 | 删除活动 | 教师 | 删除自己创建的活动；删除后学生端不再展示该活动 |
| FR-12 | 查看活动报名名单 | 教师 | 查看该活动所有报名学生账号列表 |

## 6. 非功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NFR-01 | 权限安全 | 学生不能访问教师管理页面；教师不能使用学生报名业务以外的功能；不同教师只能管理自己发布的活动 |
| NFR-02 | 可用性 | 电脑浏览器正常访问；页面操作有提示（报名成功、表单错误弹窗/提示条） |
| NFR-03 | 版本管理 | 使用 Git，每完成一个小功能做一次 commit；提交信息清晰；托管到 GitHub；禁止一次性提交全部代码，模拟迭代开发过程 |
| NFR-04 | 数据安全 | 仓库不能提交密码、密钥等敏感信息；数据库密码字段加密存储 |

## 7. V1.0 不实现清单（留给 V2.0 迭代）

1. 活动审批流程、签到、评价、评论、图片上传；
2. 文件导出 Excel；
3. 管理员角色；
4. 短信邮件通知。

V1.0 只保证最小业务闭环，符合实验要求，不追求大而全。
