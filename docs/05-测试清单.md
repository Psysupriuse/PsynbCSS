# 测试清单 — Psy剪贴板

> 全部阶段完成后,按本清单逐项总验收;各开发阶段的验收标准见 docs/04-开发步骤与验收标准.md。

## A. 记录

- [ ] 复制纯文字 → 列表顶部出现该卡片
- [ ] 复制图片(如微信截图)→ 列表顶部出现缩略图卡片
- [ ] 连续复制相同内容 → 不产生重复条目
- [ ] 复制"password: 12345" → 不出现(过滤开);关闭过滤后出现
- [ ] 重启应用 → 历史记录仍在

## B. 查看与操作

- [ ] 卡片按时间倒序;置顶卡片在列表最上方且带徽标
- [ ] 搜索关键词 → 实时过滤(大小写不敏感);清空搜索恢复完整列表
- [ ] 删除单条 → 条目消失;图片条目同时删除图片文件
- [ ] 清空全部(二次确认后)→ 列表为空,显示空状态提示
- [ ] 时间显示:刚刚/分钟/小时/天/超过 30 天显示完整日期

## C. 回贴

- [ ] 点击文字卡 → 自动粘贴进记事本
- [ ] 点击图片卡 → 自动粘贴进 Word/画图
- [ ] 回贴后历史不新增重复条目
- [ ] 切到"仅复制"模式 → 点击后只复制,手动 Ctrl+V 可粘贴

## D. 面板行为

- [ ] 托盘左键 → 面板在鼠标位置弹出
- [ ] 全局快捷键 Ctrl+Alt+V → 弹出/收起
- [ ] 失焦约 500ms 自动隐藏;Esc 收起;✕ 收起(均不退出)
- [ ] 托盘右键菜单各项正常;"退出"后进程结束

## E. 清理机制

- [ ] 保存期限设为 1 天 + 存在 2 天前的数据 → 启动后被清理
- [ ] 置顶的同龄条目 → 保留
- [ ] 超过 500 条 → 最旧的非置顶条目被移除

## F. 设置

- [ ] 保存期限 1/3/5/自定义全部生效并持久化(重启保留)
- [ ] 快捷键改为其他组合 → 立即生效;重启后保留
- [ ] 智能过滤 / 自动粘贴 / 开机自启开关全部生效并持久化

## G. 安装包

- [ ] 安装包安装成功,桌面快捷方式可用
- [ ] 开机自启生效(重启电脑后托盘出现)
- [ ] 首次运行 SmartScreen 提示可正常放行
