# 开发步骤与验收标准 — Psy剪贴板

版本:1.0 | 更新日期:2026-09-20

## 工作约定(所有开发必须遵守)

1. **严格按阶段顺序推进**:上一阶段验收通过后,才能开始下一阶段
2. **每个阶段结束**:更新 devlogs/当天日期.md 的"今日完成"与"待办"
3. **先文档后代码**:改动关键机制或需求变更,先更新 docs/ 对应文档,再改代码
4. **每步必验证**:改动后立即运行验证(命令见 §验证工具),不通过不进入下一阶段
5. **小而稳**:一个阶段只做一件事,不做范围外优化

## 阶段划分

| 阶段 | 内容 | 涉及文件 | 验收标准 |
|---|---|---|---|
| 0 | 文档体系与项目骨架 | docs/、CLAUDE.md、devlogs/、package.json | 文档齐全,约定可执行 |
| 1 | 主进程骨架:窗口(无边框/隐藏关闭/失焦隐藏)、托盘、全局快捷键、单实例、图标 | main.js、preload.js、renderer/(骨架)、scripts/make-icon.js、assets/ | 应用可启动不报错;托盘图标出现;托盘点击/快捷键可弹出收起面板;截图验证 UI 骨架正常 |
| 2 | 数据层:存储读写、剪贴板轮询、去重、智能过滤 | main.js | 复制文字/图片被记录;重复复制不重复;密码类内容被过滤;重启数据仍在 |
| 3 | 列表界面:卡片渲染、搜索、置顶、删除、相对时间、空状态、图片缩略图 | renderer/ | 截图/人工确认全部交互正常 |
| 4 | 自动粘贴链路 | main.js、renderer/app.js | 点击卡片后内容自动粘贴进记事本/Word |
| 5 | 清理机制:到期清理 + 容量上限 + 置顶豁免 | main.js | 造旧数据验证到期清理;置顶条目保留 |
| 6 | 设置界面:保存期限、快捷键录制、开关项、清空历史 | renderer/、main.js | 全部设置项生效并持久化 |
| 7 | 打包发布:NSIS 安装包、安装验证 | package.json、scripts/ | 安装包安装运行正常;开机自启生效 |

## 验证工具

| 命令 | 用途 |
|---|---|
| `npm start` | 启动应用(开发模式) |
| `npm test` | 数据层自检:自动跑一组断言(记录/去重/过滤/持久化/容量/到期清理)后退出 |
| `npm run uitest` | UI 交互自检:模拟真实按键/点击跑端到端断言(搜索/置顶/删除/回贴/设置)后退出 |
| `npm run shot` | 截图验证:注入示例数据、截图到 shot.png + 界面检查报告 shot-report.json 后自动退出(不影响真实数据) |
| `node scripts/make-icon.js` | 重新生成图标 |
| `npm run dist` | 打包 NSIS 安装包(首次打包工具下载慢,可用国内镜像) |

> 注意:测试会写入系统剪贴板,运行测试前请先退出正在运行的 Psy剪贴板 实例,避免测试内容被记录进真实历史。

## 备注

- 每个阶段验收通过后,在日志中记录"阶段 N 验收通过"再进入下一阶段
- 全部阶段完成后,执行 docs/05-测试清单.md 的总验收
